# Security

Dua handles personal details of participants and the integrity of judging, so
security reports are taken seriously.

## Reporting a problem

Please don't open a public issue. Use GitHub's private reporting instead: on
this repository, go to **Security → Report a vulnerability**.

Include what you found, how to reproduce it, and what an attacker could do
with it. Don't include real participants' data.

You'll get an acknowledgement within a week. Once a fix is released you'll be
credited, unless you'd rather not be.

## What matters most

- Anyone reading registrations, submissions' contact details, or another
  judge's scores without being allowed to.
- Anyone changing scores, phases or results without being allowed to.
- Getting into the admin panel without valid credentials.
- Forging submission edit links or unsubscribe links.

## Supported versions

Until 1.0, only the latest commit on `main` gets security fixes.
